# 충현 Manager

매장 원자재·레시피·원가·직원 권한을 관리하는 태블릿 대응 웹앱.

현재 상태와 실제 배포 전 남은 작업은 DEVELOPMENT_STATUS.md를 확인한다. 구현 완료와 운영 로그인·메일 발송 검증 완료를 구분한다.

개발 검증: npm ci, npm test, npm run check, npm run build.

index.html 및 core.mjs가 클라이언트다. 서버 함수와 스키마 소스는 supabase/에 있다. 데이터베이스 변경은 이미 사용자 승인하에 새 프로젝트에 적용했으므로 같은 마이그레이션을 중복 실행하지 않는다. 대표자 이메일은 공개 소스에 포함하지 않는다.

공개 배포와 운영 사이트 교체는 사용자 승인 이후에 수행한다.
