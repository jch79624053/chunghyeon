# 월말 정산 분석 상태

Google Drive 연결을 통해 사용자가 지정한 밥한술·일오·짝퉁포차 원본의 2026년 월말정산 탭을 읽었다. 정산 원본의 셀·수식·파일·공유 설정은 변경하지 않았다.

## 실제 자료 반영

- 밥한술: 2026년 1~9월, 9개 기록.
- 일오: 2026년 1~12월, 12개 기록. 10월은 매출 미입력, 11~12월은 미래 월로 별도 표시.
- 짝퉁포차: 2026년 9~10월, 2개 기록. 10월은 진행 중으로 표시.
- 총 23개 월 기록을 비공개 DB에 반영했다. 원본의 총지출과 그룹 합계가 일치하도록 검증했고, 세부합계 이상은 숨기지 않고 경고로 남겼다.
- 이번 초기 가져오기 범위는 2026년이다. 이전 연도 탭의 전체 내역은 아직 가져오지 않았다.
- 원본의 문서 ID, 실제 재무 금액, 개인별 급여 및 원본 그리드는 공개 소스나 QA 파일에 포함하지 않는다. DB에는 원본 문서 ID와 월별 집계·범주별 금액·근거 셀 주소만 저장한다. 원본 그리드는 재현 분석을 위한 작업 공간에만 둔다.

## 구현

- 월말 정산 메뉴: 매장·월 선택, 월 매출·원본 총지출·지출/매출·정산 차액.
- 항목별 매출 대비 지출 비중 막대, 월별 비교, 전월 변화와 점검 제안.
- 매출 감소로 비중만 오른 경우와 지출금액 자체가 늘어난 경우 구분.
- 0/누락 매출, 미래 월, 진행 중인 월, 세부합계 경고를 따로 처리. 자료 이상·미결산 시 절감 확정 제안 보류.
- 총지출 중 일부 공제·적립과 일회성 공사·수선은 이름을 구분해 보여주되 원본 정산 합계에서 임의로 빼지 않는다. 실제 회계 순이익으로 단정하지 않는다.
- 지출 절감 가정을 입력하면 다른 조건이 같다는 가정하의 월 차액 변화 표시. 실제 지출 감축이나 투자 확대를 자동 실행하지 않는다.
- 대표자와 매장별 승인을 받은 활성 관리자만 조회. 비밀 레시피 접근과 분리. 직원·미승인 관리자·익명 접근 차단.
- CSV 가져오기: 원본 연도별 탭 CSV를 양식 검사·미리보기 후 명시적으로 반영. 같은 매장·월은 교체하며 중복 누적하지 않음. 여러 월 저장은 단일 트랜잭션, 최신 가져오기 시점 검사로 덮어쓰기 방지.

## 원본 확인 사항

- 밥한술 6월 인건비 소계와 급여 행 합계가 다르다. 기타 지급 포함 여부를 확인하도록 표시. 원본 숫자는 변경하지 않음.
- 짝퉁포차 9월 식자재 소계 A21 수식은 B21:H21만 포함하고, 음료수 I21은 제외한다. 10월 A52는 B52:I52를 포함한다. 세부항목 초과 경고를 표시하고 해당 소계의 상세 분류는 보류한다. 원본을 자동 수정하지 않음.
- 실제 임금·계좌·개인별 내역은 정산 UI에 노출하지 않는다.

## 업데이트 방식과 남은 작업

현재는 마지막 가져오기 시점의 자료다. ChatGPT의 Google Drive 연결이 배포된 웹앱의 지속적인 Google 인증을 제공하는 것은 아니다. 상시 자동 동기화는 구현 완료로 안내하지 않는다. 사용자는 이 대화에 최신화를 요청하거나 앱에서 CSV를 가져올 수 있다.

Google 원본 접근 권한을 바꾸거나 비공개 문서를 공개 게시하는 우회는 사용하지 않았다.

Node 테스트 총 22개 통과. 새 DB에서 매장별 승인/철회, 직원·미승인 관리자 차단, 원자적 가져오기 복구, 오래된 가져오기 방지 통합 검증 통과. 통합 검증 계정과 행은 전부 rollback.
브라우저 가상 데이터 환경에서 정산 메뉴·비중·차액·절감 가정 반응을 확인. 실제 정산 정보가 공개되지 않는 QA 환경만 사용.

기존 앱 전체의 남은 배포 조건(이메일 발송 설정, 실제 대표자 로그인, 사용자 공개 배포 승인)은 그대로 남아 있다. 공개 사이트를 변경하지 않았다.
